Camera Connector / Pinout Comparison

Chronos HW_CHRONOS_R1 (Panasonic AXT524124)  vs  Waveshare OV9281-120 (Raspberry Pi 15-pin FFC)

Key finding

The Waveshare OV9281-120 uses the standard Raspberry Pi 15-pin CSI interface. This connector does NOT provide an FSIN (frame-sync / external-trigger) pin, and the module free-runs on its own on-board 24 MHz oscillator. Chronos requires FSIN to capture all 4 cameras in hardware sync (global-shutter, simultaneous). Hardware sync with this module is therefore only possible by soldering a wire to the OV9281 FSIN pad on the Waveshare PCB. A module that breaks FSIN out on the connector (e.g. Arducam with FSIN/STROBE header) avoids this.
